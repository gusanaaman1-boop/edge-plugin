EDGE — building on Windows
==========================

You need, once:

  * Visual Studio 2022 with the "Desktop development with C++" workload
    (the free Community edition is fine)
  * CMake 3.22 or newer          https://cmake.org/download/
    -> tick "Add CMake to the system PATH" in the installer
  * Git for Windows              https://git-scm.com/download/win

Then:

  1. Unzip this folder somewhere WITHOUT spaces or Hebrew in the path.
     C:\Audio\EDGE is good. The Desktop is usually fine too.

  2. Double-click        build-windows.bat

     Run it from the EXTRACTED folder - not from inside Windows' ZIP viewer.
     Opening a .bat straight out of a ZIP copies only the script to a temp
     folder, without the source. (The script now detects this and says so
     rather than failing with a confusing CMake error.)

That is the whole procedure. The script clones JUCE itself, at the exact
commit this build was tested against, so you do not have to find or configure
anything.

The first build takes 5-15 minutes because JUCE is compiled from scratch.
Later builds take under a minute.

When it finishes you get:

  build\Edge_artefacts\Release\VST3\EDGE.vst3

and the script offers to copy it to

  C:\Program Files\Common Files\VST3\

which is where Cubase looks. Copying there needs administrator rights - if it
fails, copy the folder by hand, or point Cubase's plug-in manager at the build
folder instead.

BEFORE IT COPIES ANYTHING
-------------------------
The install step refuses to run while a DAW is open - Windows will not let a
script replace a plug-in a DAW holds, and it fails silently. It also removes an
old install in BOTH shapes (a folder bundle or a stray single file), verifies
the removal before copying, and verifies the payload afterwards. If any of that
does not work, it stops and tells you which step and where.

To remove EDGE completely at any time:

  Double-click        UNINSTALL-EDGE.bat

It clears every plausible install location, both shapes, and verifies that
nothing is left behind.

IF SOMETHING GOES WRONG
-----------------------
The script stops at the first error and prints it. It never hides a failure and
never reports success it did not get. The four things that actually go wrong:

  "cmake is not recognized"    CMake is not on PATH. Re-run its installer and
                               tick the PATH option, then open a NEW terminal.
  "git is not recognized"      Same, for Git.
  "No CMAKE_CXX_COMPILER"      Visual Studio is missing the C++ workload. Open
                               the Visual Studio Installer, Modify, tick
                               "Desktop development with C++".
  It builds but Cubase does    Cubase caches its plug-in list. In Cubase:
  not list EDGE                Studio > VST Plug-in Manager > Update / rescan.
                               EDGE is filed under Filter / EQ.

WHAT YOU GET
------------
EDGE is a two-sided musical filter. One large control drives both edges of the
spectrum from open, through a shelf, to a real cut; FOLLOW lets the signal
drive it; SPREAD moves the two channels apart without changing either one's
bandwidth. See README.md for the rest.
